# شعبانی خودرو — نسخه‌ی استاتیک (Vercel)

این پوشه یک کپیِ **مستقل و بدون بک‌اند** از فرانت‌اند شعبانی خودرو است که برای
دیپلوی روی **Vercel** (یا هر هاست استاتیک) ساخته شده. تمام دیتای سایت داخل
خودش باندل شده و به هیچ سروری وصل نیست.

> نسخه‌ی اصلی و متصل به Django در پوشه‌ی `../frontend` دست‌نخورده باقی مانده است.
> این پوشه فقط برای انتشار عمومی است.

## دیتا از کجا می‌آید؟

- دیتای عمومی (محصولات، مقالات، قوانین، دسته‌بندی‌ها، نظرات، نرخ ارز) از فایل
  [`src/data/db.json`](src/data/db.json) خوانده می‌شود.
- عکس خودروها در [`public/media/uploads/`](public/media/uploads) قرار دارد.
- لایه‌ی [`src/lib/api.js`](src/lib/api.js) جای کلاینت شبکه را گرفته و همان
  درخواست‌ها را از روی `db.json` پاسخ می‌دهد. **ورود کاربر، ثبت سفارش و تیکت‌ها**
  روی `localStorage` مرورگر شبیه‌سازی می‌شوند تا کل سایت بدون سرور کامل کار کند
  (هر بازدیدکننده دیتای خودش را در مرورگر خودش دارد).

## اجرا روی سیستم

```bash
npm install
npm run dev        # روی http://localhost:5181
```

## بیلد و دیپلوی روی Vercel

```bash
npm run build      # خروجی در dist/
```

در Vercel:
- **Framework Preset:** Vite
- **Build Command:** `npm run build`
- **Output Directory:** `dist`
- **Root Directory:** همین پوشه (`frontend-static`)

فایل [`vercel.json`](vercel.json) روتینگِ SPA را هندل می‌کند (همه‌ی مسیرها به
`index.html` می‌روند) تا رفرش صفحات داخلی مثل `/products` و `/product/...` خطا ندهد.

## به‌روزرسانی دیتا (وقتی در پنل ادمین چیزی عوض شد)

هر وقت در بک‌اند/پنل، خودرو یا قیمت یا مقاله‌ای را عوض کردی، این نسخه را تازه کن:

```bash
bash ../backend/run.sh          # بک‌اند را بالا بیاور (پورت ۸۰۰۱)
python3 scripts/snapshot.py     # db.json و عکس‌ها را دوباره می‌سازد
npm run build                   # و دوباره دیپلوی کن
```

## نرخ درهم → تومان

قیمت تومانی هر خودرو = `قیمت درهم × نرخ`. مقدار نرخ در `src/data/db.json` کلید
`rate` است (همان چیزی که موقع اسنپ‌شات در پنل تنظیم بوده). اگر خواستی سریع عوضش
کنی، فقط همان عدد را در `db.json` تغییر بده و دوباره `npm run build` بزن.
